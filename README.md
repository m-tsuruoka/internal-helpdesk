# ヘルプデスクアプリ

社内問い合わせを管理するブラウザアプリです。

## 機能

- 問い合わせの一覧表示
- 詳細表示
- 新規登録
- ステータス更新（未対応 / 対応中 / 完了）
- ステータスでのフィルタリング
- idでの並び替え
- 削除機能

## 技術スタック

- React 19.2.7
- TypeScript 6.0.3
- Vite 8.0.16
- react-hook-form

## 起動方法

\```bash
npm install
npm run dev
\```

## 注意

ブラウザをリロードするとデータがリセットされます（useState で管理しているため）。
